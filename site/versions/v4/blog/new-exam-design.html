My proposal for the Dutch national exam design

2026-05-24 CEST · 2 min read · 358 words

This is a follow-up to my post about the new Dutch exam design

Instead of only just complaining, I decided to actually design something better. My proposal is based quite a bit on old design, because I still think the old design gets most things right. But it also fixes a few things that were already slightly off (before the CvTE made them even worse).

The cover

The cover has a few things to communicate: the subject, the school level, the year, the tijdvak (which sitting of the exam it is, because there are multiple each year), the date and time, and which document you're holding. For the exercise booklet specifically, it also shows the number of questions and the maximum score.

Not all of that is equally important. When you pick up the booklet, the first thing you need to know is what you are holding. I would say that subject, year, and document type need to be immediately obvious. Date and time matter much less. So in my design, those three key pieces are the largest and boldest, and everything secondary is smaller and quieter.

I also removed the code in the bottom-left corner that appears on current exams. That code is for administrative use and no student has ever needed it. I replaced it with something actually useful: a clear description of the document and exam (which can also still be used for administrative purposes).

The rest of the exam

The body of the exam is very simple: black text on a white background, no decorative shapes, no grey boxes, no icons.

I dropped the word "Vraag" before every question number, because it adds no information. Everyone already knows what a question number is (and if you don't, you probably shouldn't be making exams).

Point values are back in front of the question number, making it easy to scan down a page and understand how points are distributed.
